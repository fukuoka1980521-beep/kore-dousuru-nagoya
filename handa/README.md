# どうする半田 CURRENT

半田市の暮らし・行政手続ナビと、補助金・助成金の申請アシスト実証版です。

## 現在の主要機能
- ごみ・手続・相談先ナビ
- 自由入力から自治体・国の公式制度候補を提示
- 「契約社員を正社員にしたい」等からキャリアアップ助成金・正社員化コースへ接続
- PDF／写真の提出前チェック
- キャリアアップ助成金・正社員化コース（令和8年4月8日以降）のFORM RULE PACK
- 書類同士の氏名・会社名・転換日・計画期間・規程施行日の照合
- 6か月分の月別賃金台帳の不足／重複／合計候補
- 3％賃金増額の計算候補
- 賃金締日がある場合は比較期間を自動推測せず人間確認
- 令和8年10月1日以降の生涯設計手当・企業型確定拠出年金の取扱変更警告
- 取組日がFORM RULE PACK対象外なら停止
- 結果の印刷／PDF保存
- 20ページを超えるPDFは未読ページを警告
- FORM RULE PACK版・公式確認日・解析対象ファイルを結果に表示

## 安全境界
- OCRで読めないものを「不足」「問題なし」と断定しません。
- 草案・下書きを正式資料として扱いません。
- 3％以上でも「計算候補」であり、支給要件充足・受理・支給を保証しません。
- 未対応制度に別制度のルールを流用しません。
- ファイルはブラウザ内で解析し、サイト側へ保存しません。
