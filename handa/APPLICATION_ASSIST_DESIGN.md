# Application Assist Design

## 目的
「制度を探す」だけで終わらず、本人が作成した申請資料を提出前にセルフチェックし、次に直すことまで示す。

## 共通フロー
Situation → Candidate → Official Source → Documents → FORM RULE PACK → Cross-document Consistency → Wage Audit → Next Action

## 判定状態
- 確認できた / 一致
- 計算候補
- 不一致候補
- 要確認
- 不足候補
- 判定不能
- 草案・下書き
- 要更新確認
- 後の申請段階
- 条件付き
- 人間確認
- 停止

## 重要原則
- 公式情報にない事実は生成しない。
- OCR失敗と未添付を区別する。
- 草案・後日確認資料を正式原本と同一視しない。
- 取組日で適用ルールを先に確定する。
- 3％計算は根拠値が安全に揃った場合だけ「候補」を表示する。
- 賃金締日がある場合、比較6か月を自動推定しない。
- 結果は「次にすること」を最上段に出す。

## 監査可能性
- PDFの未読ページを黙って切り捨てない。
- 判定に使ったファイル名、FORM RULE PACK版、公式確認日を結果に残す。
- 解析ライブラリ等の外部配信元利用を利用者に明示する。
